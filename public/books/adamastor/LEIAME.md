# Clássicos da Literatura: como cadastrar os EPUBs

Os 12 livros ficam em `public/books/adamastor/` com o nome `<id>.epub`. Duas formas de colocá-los:

1. **Automática (recomendada):** no GitHub, aba *Actions* → *Baixar clássicos do Projecto Adamastor* → *Run workflow*. O GitHub baixa, valida e cadastra tudo.
2. **Manual:** baixe os arquivos abaixo no navegador e envie-os para esta pasta (*Add file → Upload files*, qualquer nome serve). O mesmo fluxo roda sozinho, confere o título e renomeia.
